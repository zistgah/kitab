# Contract — zistgah/kitab

kitab is a reusable book template. It carries no book-specific content of its own;
every book is config + content. See zistgah/governance for the master clauses.

- Plumbing GPL-3.0-or-later; content licence per book.config.json; metadata CC0-1.0.
- The litigation-simulation hook (C34) is present in the reader chrome as a
  configurable entry (default: stub → zistgah/vakil).
- Contributions default to the plumbing licence for code and CC-BY-SA-4.0 for docs;
  the owner retains acceptance discretion.
